# 2. 牙位识别

**实现状态：已接入现场识别和导板映射。** 未配置病例 YAML 时记录为 `skipped`。

## 功能

本阶段根据病例 YAML 现场生成并校验 `tooth_guide_mapping.json`，保留 FDI
顺序、present/missing/excluded 牙位、牙冠中心点、牙弓坐标和观察窗端点。
自动坐标方向存在左右两个候选时，还会把缺失牙预测位置投影到牙弓平面，
与激活导管 STL 的面积加权中心比较：最佳距离必须不超过 15 mm，且相对
另一方向至少领先 3 mm。满足时允许该检测覆盖单纯语义评分；两方向都过远
或差异不足时立即停止，不带着不确定的左右方向进入后续梁架生成。
