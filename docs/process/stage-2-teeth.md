# 2. 牙位识别

**待实现的扩展。** 当前运行生成过程时，本步骤记录为 `skipped`。

## 功能

在患者牙列扫描中识别单颗牙齿，建立牙位标签、表面区域与病例坐标系的对应关系。

## 输入

- `GenerationContext.config.inputs.patient_dentition`：患者牙列扫描 STL。
- `CaseAnalysis.template_frame`：牙科导板局部坐标系。

## 目标输出

计划输出应记录每颗牙齿的牙位标签、表面区域、几何中心和识别诊断。
当前源码尚未定义对应的结果类型。

## 目标依赖

目标接口直接读取患者牙列及其配准坐标信息，不把第 1 步的导套重建作为前置条件。
实现后，其结果可用于将当前的几何启发式观察窗升级为牙位驱动的定位，
也可为按压结构和牙列净距检查提供牙齿表面区域。

当前源码虽读取牙列 STL，但还没有实现单颗牙齿分割或牙位标注。

## 处理逻辑

1. 读取患者牙列网格并转换到病例局部坐标系。
2. 分割单颗牙齿的表面区域。
3. 根据牙弓排列和几何邻接关系分配牙位标签。
4. 记录区域边界、几何中心和无法唯一标记的牙位。

## 配置参数

目标接口需定义分割尺度、最小牙齿区域和标签置信度阈值。

## 异常与诊断

网格坐标系不一致、牙齿区域无法分离或牙位不可唯一确定时，结果应记录对应区域和失败原因。
