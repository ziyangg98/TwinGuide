# 第 6 步：连接梁生成

**实现状态：实验。** 本阶段将导管端、导板端和可选按压梁锚点转换为连续中心线
计划，输出 `PointLinkingPlan`。

## 连续框架

1. 单种植位每根导管生成上、下两根连续梁。
2. 高梁使用分段五次 Hermite 曲线经过导管高端接触点。
3. 低梁沿外层代理曲线接近导管，再在局部弧长内下潜到深埋接触点。
4. 多种植位按病例声明的同侧路径依次穿过各导管，不拆成互不相连的独立梁。
5. 末端病例可以让上下路径共享远中公共节点，或加入经过审核的 U 型延伸。
6. 按压梁、跨组件桥接和导板端贴合脚作为同一计划中的显式附加结构传递。

当前只有连续框架实现；旧版独立 Bézier 连接器已经删除。连接梁侵入牙列或导孔的
部分由 Blender 实体化阶段按配置净距裁切，最终融合后执行规定的导孔复切。
