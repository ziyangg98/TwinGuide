# 6. 光滑连接管生成

## 功能

使用光滑曲线连接导套侧与牙科导板侧锚点，将中心线实体化为连接管，
并在布尔融合后复切导套内部的固定孔。

## 输入

- `TemplateLinkPointPlan`：导套与牙科导板锚点。
- 病例配置中的连接柱直径，以及 `PointLinkingConfig` 中的贝塞尔控制柄和曲线分辨率。

当前代码不读取预留的第 5 步结果；按压梁柱实现后，其连接端点需要接入本步。

## 输出

`PointLinkingPlan` 记录连接标签、三次贝塞尔控制点、离散中心线和固定孔复切设置。

## 依赖关系

当前本步只读取第 4 步的锚点。完成后的曲线管与切口导板、重建导套一同进入 Blender 实体化和布尔融合。

## 处理逻辑

1. 每个导套的上下锚点分别连接牙科导板左右点，形成一个 $K_{2,2}$；两个导套共生成八条连接。
2. 起点控制柄沿导套径向伸出，终点控制柄沿朝向导套的表面法向伸出。
3. 根据端点距离和连接柱直径确定控制柄长度，生成三次贝塞尔曲线。
4. Blender 将曲线转换为带圆形截面和端盖的连接管网格。
5. 连接管与导套、牙科导板融合后，使用导套固定孔圆柱再次切除侵入部分。

## 配置参数

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `geometry.connector_diameter_mm` | 2.30 | 连接柱直径 |
| `handle_factor` | 3.0 | 控制柄长度系数 |
| `curve_resolution` | 24 | Blender 曲线轴向细分 |
| `recut_sleeve_bore` | `True` | 是否复切导套固定孔 |
