# 生成过程

当前程序逐装配体识别具有真实轴孔的两个导管，复用识别位姿并按病例 YAML
的标准尺寸重建导管，执行 FDI 牙位映射，
在导板上切出导孔和窗口，为每个导管选择高低 Q/P 及基于牙位射线的导板锚点，
生成四根连续曲线梁；还可按配置生成 Y 型按压梁、两分量跨接梁、末端 U 型延伸梁、
末端牙龈公共节点和手机避让切除。导管、导板和梁架整体融合后，统一复切导孔和
观察窗，再完成 STL 导出。

源码以 `GenerationContext` 传递阶段结果。完整的当前建模思想、参数语义、特殊病例接口和
质量检查见[《TwinGuide 建模技术说明》](../guide/technical-modeling-workflow.md)。

牙位识别按病例配置执行；按压结构、特殊拓扑和手机避让均为可选阶段，未配置时为
`skipped`。

## 当前算法主线

| 步骤 | 最小几何逻辑 |
| --- | --- |
| 1. 导管 | 七点导孔检查后按尺寸、平行度和位置选对；复用精确位姿并按八个标准参数重建 |
| 2. 牙位 | 运行病例级牙位工作流，生成 FDI 映射、牙弓局部方向并校验左右坐标一致性 |
| 3. 切口 | 导孔沿导管轴线；操作窗覆盖两导管间的操作结构；观察窗按 FDI 范围和牙弓方向生成 |
| 4. 锚点 | 在 C 口反向外壁生成 Q/P；从牙位 T 点按配置角度发射射线，取导板外壁出口 A |
| 5. 按压结构 | 按模式选择导管高端、三个牙位点或末端 U 梁点，生成三锚点 Y 及抬高汇合点 |
| 6. 连接 | 每个导管生成 `A−→P高→A+` 与 `A−→P低→A+`；按需加入 Y 梁和特殊病例梁 |
| 7. 净距 | 以止挡报告确定手机旋转轴/枢轴，精确合并当前深度左右摆动姿态，最终整体直接差集 |
