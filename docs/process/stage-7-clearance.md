# 7. 避让空间调整

**实现状态：待实现。** 当前运行生成过程时，本步骤记录为 `skipped`。

## 功能

检查完整联建结构与患者牙列、牙科手机运动包络和导套功能区的净距，
调整连接结构以消除干涉。

## 目标输入

- `PointLinkingPlan` 及实体化后的完整网格。
- 患者牙列扫描、牙科手机网格和运动采样参数。
- 导孔、窗口和固定孔等必须保留的功能区。

## 目标输出

计划输出应包含调整后的几何计划、各检查对象的最小净距、调整记录和未解决的干涉。
当前源码尚未定义对应的结果类型。

## 依赖关系

该步骤读取第 2、3、6 步结果，输出交给 Blender 建模层和结果检查。

## 处理逻辑

1. 建立患者牙列、牙科手机运动包络和功能保护区的距离查询结构。
2. 计算连接管与各检查对象的最小距离，标记低于阈值的曲线段。
3. 在保持端点、连接柱直径和功能区边界的条件下调整曲线控制点。
4. 重新实体化和计算净距，直至达到阈值或确定无可行调整。
5. 完成布尔融合、固定孔复切和网格检查。

## 配置参数

目标接口需定义患者牙列、牙科手机和功能保护区的最小净距，以及曲线调整步长和迭代上限。

## 异常与诊断

输入网格坐标系不一致、距离查询失败或无可行调整时，记录干涉位置、实际净距和目标阈值。
