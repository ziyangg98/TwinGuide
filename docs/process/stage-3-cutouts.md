# 3. 导孔与窗口规划

## 功能

根据导套位置和装配体中的操作结构，规划导孔、操作窗和观察窗的切割几何。

## 输入

- `CaseAnalysis`：牙科导板表面、局部坐标系和操作结构尺寸。
- `SleeveGenerationResult`：导套轴线、固定孔半径和轴向范围。
- 牙位与牙面识别结果：用于确定观察窗对应的牙齿和表面区域；当前尚未接入。

## 输出

`WindowCutoutPlan` 包含两个导孔有限圆柱、操作窗和观察窗的位置、方向与尺寸。

## 依赖关系

正确的观察窗定位依赖牙位与牙面识别结果。导孔和操作窗依赖病例分析与导套结果。
本步的切口边界供后续联建锚点选择和功能区避让使用。

**当前代码限制：** `plan_window_cutouts()` 只接收病例分析和导套结果。
它在导板左右外侧用几何启发式放置观察窗，尚不能保证窗口对准所需牙齿或牙面。

## 处理逻辑

1. 沿导套轴线生成带轴向余量的导孔切割体。
2. 根据装配体中的操作结构、两导套间距和局部导板深度构造操作窗。
3. 使用牙位和牙面区域选择观察目标，将观察窗定位到对应导板表面。
4. 检查观察窗与导孔、操作窗及必须保留的结构是否重叠，调整不可行的窗口。

## 配置参数

`template_channel_radius_mm` 和 `channel_axial_margin_mm` 控制导孔尺寸；
`operation_tangent_margin_mm` 和 `operation_bitangent_margin_mm` 分别控制操作窗沿切向和副切向的外扩余量。

## 异常与诊断

病例分析与导套结果不一致时抛出 `ValueError`。无法找到有效表面样本或切口无法分离时记录几何诊断。
