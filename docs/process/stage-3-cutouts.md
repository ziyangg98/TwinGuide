# 3. 导孔与窗口规划

## 功能

根据导套位置和装配体中的操作结构，规划导孔、操作窗和开放式观察缺口。

## 输入

- `CaseAnalysis`：牙科导板表面、局部坐标系和操作结构尺寸。
- `SleeveGenerationResult`：导套轴线、固定孔直径和轴向范围。

## 输出

`WindowCutoutPlan` 包含两个导孔有限圆柱、操作窗和观察缺口的位置、方向与尺寸。

## 依赖关系

导孔和操作窗依赖病例分析与导套结果。
本步的切口边界供后续联建锚点选择和功能区避让使用。

## 处理逻辑

1. 沿导套轴线生成带轴向余量的导孔切割体。
2. 对非导柱分量做局部主方向分解，选取靠近两导柱中点的近圆形结构，用其自身局部平面尺寸确定操作窗。
3. 从导板前缘中线的表面点出发，在患者牙列 STL 中取最近牙面，
   将观察缺口对准该牙面，并按 `jaw` 将开放边定向到牙合侧。
4. 以牙面高度作为切口下缘，使缺口刚好露出牙齿；切割深度覆盖局部导板厚度。

## 配置参数

`sleeve.inner_diameter_mm` 和 `channel_axial_margin_mm` 分别控制导孔直径和轴向余量；
`operation_tangent_margin_mm` 和 `operation_bitangent_margin_mm` 分别控制操作窗沿切向和副切向的外扩余量。
当前病例的导孔直径为 2.10 mm。
观察缺口宽度为 7.0 mm，位置和下缘由导板前缘与患者牙列的最近对应确定。
切入深度为局部表面法向厚度加两侧 0.8 mm 余量。
