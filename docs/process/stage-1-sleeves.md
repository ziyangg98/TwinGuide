# 1. 导套识别与参数化重建

## 功能

从导套装配体的连通分量中识别两个导套，估计轴线和平台方向，并使用病例配置
中的尺寸参数构建可用于后续布尔运算的闭合导套实体。

## 输入

- `SleeveGenerationInputs.components`：装配体连通分量。
- `template_bvh`、`template_samples`、`template_center`：用于导套定向和排序的牙科导板几何。
- `sleeve_parameters`：导柱内径 $2R_{\mathrm{in}}$、主体外径
  $2R_{\mathrm{out}}$、总高度 $H$、平台径向长度 $W_{\mathrm p}$、平台段高度
  $h_{\mathrm p}$、闭合孔段高度 $h_{\mathrm s}$、内圆弧覆盖角
  $\phi_{\mathrm{in}}$ 和主体外圆弧覆盖角 $\phi_{\mathrm{out}}$。

## 输出

`SleeveGenerationResult` 包含两个 `GuideSleeve` 和牙科导板局部坐标系。
每个导套记录轴线、总高度、内外直径、平台参数和重建误差。

## 依赖关系

该步骤依赖输入网格和病例配置中的完整 `sleeve` 参数，当前为第 3、4 步提供导套几何。
预留的牙位识别接口不依赖本步的导套重建结果。

## 处理逻辑

1. 分离导套装配体的连通分量并采样表面。
2. 根据主轴、轴向范围、径向尺寸和长径比建立导套候选。
3. 枚举候选对，检查轴线平行度、尺寸差和中心间距。
4. 使用导套轴线与牙科导板的交点统一轴向，并按局部横向排序。
5. 估计导套轴线与平台方向，将配置中的八个几何参数写入参数模型，生成闭合
   网格，计算原网格与重建网格的双向表面误差。

## 配置参数

候选筛选阈值在 `sleeve_generation.py` 中定义。网格测量用于识别导柱候选、确定
轴线和平台方向；重建尺寸取自病例配置。当前参数见 `examples/case.json`。

## 异常与诊断

候选分量过小、无可行导套对、局部坐标系退化、参数无效或闭合重建失败时抛出 `GeometryError`。
参数诊断和重建误差保存在导套结果中。
