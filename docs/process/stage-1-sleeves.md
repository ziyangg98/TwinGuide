# 1. 导套识别与参数化重建

## 功能

从导套装配体的连通分量中识别两个导套，估计轴线和 C 口方向，并使用病例配置
中的尺寸参数构建可用于后续布尔运算的闭合导套实体。

## 输入

- `SleeveGenerationInputs.components`：装配体连通分量。
- `template_samples`、`template_center`：用于建立牙科导板局部标架并排序。
- `sleeve_parameters`：导柱内径 $2R_{\mathrm{in}}$、主体外径
  $2R_{\mathrm{out}}$、总高度 $H$、平台径向长度 $W_{\mathrm p}$、平台段高度
  $h_{\mathrm p}$、闭合孔段高度 $h_{\mathrm s}$、内圆弧覆盖角
  $\phi_{\mathrm{in}}$ 和主体外圆弧覆盖角 $\phi_{\mathrm{out}}$。

## 输出

`SleeveGenerationResult` 包含两个 `GuideSleeve` 和牙科导板局部坐标系。
每个导套记录轴线、C 口方向和八个标量尺寸参数。

## 依赖关系

该步骤依赖输入网格和病例配置中的完整 `sleeve` 参数，当前为第 3、4 步提供导套几何。
预留的牙位识别接口不依赖本步的导套重建结果。

## 处理逻辑

1. 分离导套装配体的连通分量并采样表面。
2. 枚举分量对，按与已知导柱高度、外径的差异和两轴平行程度排序，取最优对。
3. 用内孔的五个截面圆心对主轴作一次修正。
4. 比较两个轴向端部的截面拓扑，将带闭合内孔的平台端定义为轴向正向；轴向由输入 STL 决定，不由上下颌翻转。
5. 将两导柱中心连线投影到各自轴线法平面，作为分别指向另一导柱的 C 口方向；
   再将位姿与配置中的八个尺寸组合，生成闭合网格。

## 配置参数

网格测量用于识别导柱候选和确定轴线；C 口方向由两导柱的相对位置确定，
八个重建尺寸取自病例配置。
当前参数见 `examples/case-tooth-47.json`。
