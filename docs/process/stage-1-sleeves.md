# 1. 导管识别与标准重建

## 功能

从每个导管装配体的连通分量中识别两根具有真实轴孔的导管，估计轴线、
精确位姿和 C 口方向，再按病例 YAML 的八个标准尺寸重建导管。
输入装配体只提供识别位姿和操作结构，不直接进入最终模型。

## 输入

- `SleeveGenerationInputs.components`：单个装配体的全部连通分量。
- `template_samples`、`template_center`：建立导板局部标架并排序导管。
- `sleeve_parameters`：标准导管的八个解析尺寸，也是候选尺寸评分基准。
- `jaw` 与 `occlusal_axis`：上下颌及病例坐标中的牙合外向，用于统一导管轴向符号。

## 输出

`SleeveGenerationResult` 包含当前种植位的两个标准 `GuideSleeve` 和导板
局部坐标系。每个导管记录轴线、C 口方向和标准尺寸。

## 候选识别

1. 分离装配体连通分量并采样表面，拟合每个候选的主轴、长度、半径和中心。
2. 在拟合轴线的 15%、25%、35%、50%、65%、75%、85% 七个位置检查导孔。
3. 仅保留至少五个探测点位于导孔的候选。实心 cutter 的轴线位于实体内部，
   因而不会参与后续导管配对；可用候选少于两根时失败关闭。
4. 枚举剩余候选对，按长度、外径与配置值的差异及两轴平行程度排序。
5. 用内孔截面拟合精确轴线，再直接按上下颌的牙合外向统一轴向符号；
   不再增加端部拓扑投票或导板内向二次判断。
6. 将两导管中心连线投影到各自轴线法平面，得到分别指向另一导管的 C 口方向。

尺寸和平行度用于在已经确认具有轴孔的组件中排序，不能使实心 cutter 获胜。

## 标准重建

识别位姿与 `runtime.sleeve` 的八个解析尺寸组合为规则标准导管。
导管、导板和连接梁整体融合后，统一复切导孔和观察窗。
