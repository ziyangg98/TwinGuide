# 1. 导管识别与实体模式选择

## 功能

从每个导管装配体的连通分量中识别两根具有真实轴孔的导管，估计轴线、
几何高低端和 C 口方向，并按病例 YAML 选择参数化重建或直接采用输入实体。
识别位姿、锚点和后续切口规划在两种模式下共用。

## 输入

- `SleeveGenerationInputs.components`：单个装配体的全部连通分量。
- `template_samples`、`template_center`：建立导板局部标架并排序导管。
- `sleeve_parameters`：标准导管的八个解析尺寸，也是候选尺寸评分基准。
- `sleeve_geometry_mode`：`generated` 或 `input`。
- `occlusal_axis`：病例确认的牙合方向，用于统一导管轴向符号。

## 输出

`SleeveGenerationResult` 包含当前种植位的两个 `GuideSleeve` 和导板局部坐标系。
每个导管记录轴线、C 口方向、尺寸、源组件编号、轴向孔道通过率，并在
`input` 模式下保存所选输入网格。

## 候选识别

1. 分离装配体连通分量并采样表面，拟合每个候选的主轴、长度、半径和中心。
2. 在拟合轴线的 15%、25%、35%、50%、65%、75%、85% 七个位置采样。
   轴线上位于实体外部的比例记为轴向孔道通过率。
3. 仅保留通过率不低于 0.60 的候选。实心导孔占位 cutter 的轴线位于实体内部，
   因而不会参与后续导管配对；可用候选少于两根时失败关闭。
4. 枚举剩余候选对，按长度、外径与配置值的差异及两轴平行程度排序。
5. 用内孔截面和端部拓扑修正轴线及几何高低端，再结合病例牙合方向统一符号。
6. 将两导管中心连线投影到各自轴线法平面，得到分别指向另一导管的 C 口方向。

尺寸和平行度用于在已经确认具有轴孔的组件中排序，不能使实心 cutter 获胜。

## 两种实体模式

`case.yaml` 使用以下字段选择实体来源：

```yaml
design:
  sleeve_geometry:
    mode: input  # 或 generated
```

- `generated`：将识别位姿与 JSON 的八个解析尺寸组合，重建规则标准导管。
  后续允许导管、导板和连接梁整体融合，再对最终整体复切导孔。
- `input`：直接采用通过识别的原始导管组件。锚点投射到真实外壁，功能切割
  先作用于导板和连接梁基础体，输入导管最后作为受保护实体融合。

未配置时使用 `generated`，以保持旧病例兼容行为。当前正式病例均在 YAML 中
显式声明模式，便于审计。
