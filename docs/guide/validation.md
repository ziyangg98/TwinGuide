# 结果检查

`validate_guide()` 读取已导出的 STL，返回一组 `ValidationResult`。
每项结果包含检查名称、是否通过及数值指标。

| 检查项 | 检查内容 |
| --- | --- |
| 网格拓扑 | 边界边、非流形边、重复三角形和连通分量数 |
| 导套保留 | 参数化重建表面在最终网格中的保留比例 |
| 连接管 | 中心线样本的实体包含率及两端到导套与牙科导板的距离 |
| 导孔 | 导孔内部采样点是否被最终网格阻塞 |
| 窗口 | 操作窗和观察窗的中面采样点是否保持开放 |
| 牙科手机净距 | 运动扫掠体与最终网格的三角面重叠、相互包含和最小距离 |

检查失败时，使用 `metrics` 中的计数、比例、距离和阈值定位异常几何。
