# 结果检查

`validate_guide()` 读取已导出的 STL，返回一组 `ValidationResult`。
每项结果包含检查名称、是否通过及数值指标。

| 检查项 | 检查内容 |
| --- | --- |
| 网格拓扑 | 边界边、非流形边、重复三角形和连通分量数 |
| 导套保留 | 参数化重建表面点位于最终实体内部或距其表面不超过 0.4 mm 的比例 |
| 连接管 | 中心线样本的实体包含率及两端到导套与牙科导板的距离 |
| 导孔 | 导孔内部采样点是否被最终网格阻塞 |

导套保留率的通过阈值为 0.90；被导板或连接管包入实体内部的导套表面仍计为保留。
第 7 步当前仅为占位。
