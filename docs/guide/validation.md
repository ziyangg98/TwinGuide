# 结果检查

## 检查接口

`validate_guide()` 读取已导出的 STL，并按当前病例配置重新建立检查基准，返回
一组 `ValidationResult`。每项结果包含检查名称、是否通过及数值指标；检查函数
不修改最终模型。建立基准时会调用 `run_generation_process()`，所以验证不是纯只读
文件操作：它可能更新病例输出目录的阶段 JSON 和第 2 阶段缓存。

## 检查项目

| 检查项 | 检查内容 |
| --- | --- |
| `topology` | 边界边、非流形边、重复三角形、连通分量数和最小分量顶点数 |
| `guide_retention` | 标准重建导管表面位于最终实体内部或距表面不超过两个融合体素的比例 |
| `guide_connectors` | 主连接梁中心线的包覆率、导管接触距离和导板锚点距离 |
| `connector_endpoint_reinforcement` | 每个唯一导板端的根部球和曲面贴合脚覆盖率 |
| `press_beam` | 已配置 Y 梁三臂、汇合点和导板端强化的保留情况 |
| `terminal_distal_common_node` | 远中自由节点的基点、方向、两外径偏移、四梁共节点和闭合段保留 |
| `guide_component_bridge` | 同侧双梁是否跨越不同导板分量，以及中心线与两端保留 |
| `guide_terminal_u_extension` | U 型梁根部、两侧段、回转点、远中方向、牙冠净距和中心线保留 |
| `channels` | 每个导孔多截面、多半径探针是否被最终实体阻塞 |
| `observation_windows` | 每个 FDI 观察窗的样本净空和局部阻塞数量 |

## 主要阈值

贴合脚验证与生成器共用 77% 最小自适应足印比例，并在同一局部同向导板表面
计算探针；观察窗要求轴线样本到最终实体至少保持 0.20 mm 净距。

导管保留率通过阈值为 0.90，以识别位姿和配置尺寸重建的标准导管为参考。
被导板或连接梁包入实体内部的导管表面仍计为保留。
主连接梁保留率只检查生成计划中应当保留的中心线：统一复切的全部关联导孔和显式牙列净距
裁剪区域不计入分母，其余样本仍必须达到 0.95。

`channels` 除阻塞数量外，还记录是否在整体融合后执行了全局导孔复切。
导孔检查在奇偶射线与最近表面法向
侧别冲突时，以孔腔侧局部表面方向排除三角交线误投票。

## 条件检查

手机包络差集只由 `generate` 应用到模型。`validate` 为重建七阶段基准可能计算或
复用第 7 阶段包络计划，但当前返回结果中没有独立的手机包络净距检查，也不会再次
对待检查 STL 执行差集。特殊检查只在对应计划存在时返回；其几何语义见
{doc}`../process/special-topologies`。

现有 12 个规范病例实际返回的检查项、数值范围和逐例结果见
{doc}`case-results`。
