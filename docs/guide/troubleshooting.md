# 性能与问题定位

## 主要耗时来源

| 计算 | 相对成本 | 主要原因 |
| --- | --- | --- |
| 配置、锚点与曲线数学 | 低 | 少量点和向量运算 |
| 导管识别与牙位射线求交 | 低到中 | 网格分量分析与空间查询 |
| 牙位识别与导板映射 | 中到高 | 牙冠投影、分割、FDI 排序和表面映射 |
| 观察窗差集 | 高 | 多个轴扫切除体与复杂导板求差 |
| 梁架牙列净距修剪 | 高 | 复杂牙列保护体的布尔运算 |
| 全结构体素融合 | 高 | 高分辨率三维离散与表面重建 |
| 手机摆动包络与差集 | 很高 | 多姿态网格精确并集和最终整体求差 |
| 完整验证 | 中到高 | 重建计划、读取 STL 并逐项执行几何检查 |

调参时按“`process` 规划 → 阶段 JSON/PNG → `generate` 完整实体化
→ `validate`”逐级检查，可避免在明显的牙位或锚点错误上重复支付布尔成本。

## 常见问题

### 导管识别失败

查看第 1 阶段错误中每个连通分量的七点导孔通过数、高度/外径误差、平行度和索引。
一个种植位必须在它自己的装配体内找到两个至少 `5/7` 探针畅通的导管分量。

### 锚点跑到导板顶部

依次检查牙合轴、牙位 T 点、局部旋转面参考方向、射线角、外壁进出判定和导板分量归属。

### U 侧和背 U 侧落在同一侧

检查牙弓 `local_outward`、射线旋转符号和导板分量标签。屏幕左右不能代替牙弓
U/背 U 语义。

### 低端梁异常弯折

检查局部下潜段两侧拼接点是否继承外层曲线各自的切向。只有深埋 P 点处才使用两个合并点的连线方向。

### 导孔堵塞或观察窗消失

查看第 3 阶段计划是否正确，再确认全部结构融合后已经复切，切除体是否覆盖完整轴向范围。
融合前存在切口不能证明最终 STL 中仍然畅通。

### 导板末端被大量切除

区分第 3 阶段操作窗与第 7 阶段手机包络。前者重点检查
`operation_bitangent_margin_mm`，后者检查止挡报告的旋转轴/枢轴、摆角和额外净距。

### 特殊梁方向反了

检查 FDI 右→左顺序、病例牙合轴、参考邻牙到末端牙/牙槽位的远中向量，
以及远中公共节点叉积候选的符号选择。应修正病例语义或局部方向构造，不为单一病例翻转全局 X/Y 轴。
