# TwinGuide 建模技术说明

本文档说明 TwinGuide 当前版本从病例输入到最终 STL 的完整建模流程，重点记录每一步为什么存在、采用了什么几何思想、如何执行、读取哪些配置，以及失败时如何诊断。

本文描述的是当前统一框架，不是单个病例脚本。`#13`、`#14`、`#17` 等病例所需的特殊拓扑通过显式配置插入同一流程，而不是另建一套互不兼容的程序。

## 1. 项目目标与基本设计思想

TwinGuide 的目标是把以下输入自动组合为可制造的双导管手术导板：

- 原始牙列或牙龈网格；
- 原始导板网格；
- 导管装配体或可供识别导管位姿的网格；
- 病例级牙位、观察窗、梁架、避让和特殊拓扑参数。

最终模型通常包含：

- 参数化重建或直接保留输入实体的两根 C 型导管；
- 与两根导管相连的四根主连接梁；
- 可选的 Y 型按压梁；
- 可选的断裂导板跨接梁、末端 U 型延伸梁或末端远中公共节点；
- 导孔、两导管之间的操作窗、牙位观察窗和手机避让切除。

整个框架遵循四个原则：

1. **解剖语义优先。** 牙位、近远中方向、U 型牙弓内外侧和牙合方向不能仅由全局 XYZ 猜测，而应来自病例牙位映射。
2. **锚点与实体生成分离。** 先确定表面接触点和梁中心线端点，再生成曲线及扫掠实体，避免把网格布尔误差带入定位过程。
3. **特殊病例显式配置。** 只有真正需要的病例才启用断裂导板跨接、末端 U 型延伸或远中公共节点，普通病例不受影响。
4. **按导管模式安排复切。** `generated` 模式在整体融合后复切导孔；
   `input` 模式先从导板和梁架基础体复切导孔，再融合受保护的输入导管。
   两种模式都恢复观察窗，防止体素融合填塞功能开口。

## 2. 配置分层与病例准备

### 2.1 YAML：解剖和人工设计语义

病例 `case.yaml` 保存需要人工确认或由病例资料提供的语义信息，例如：

- 上颌或下颌；
- 实存牙、缺失牙、排除牙；
- 牙位顺序或必要时的显式坐标轴；
- 观察窗涉及的牙位范围；
- Y 梁导板锚点的 `tooth_center` 或 `tooth_pair_midpoint` 及各自射线角度；
- 手机避让所需的操作范围；
- `guide_component_bridge`、`guide_terminal_u_extension`、`terminal_distal_common_node` 等病例特征。

YAML 不直接生成网格，它表达“这个病例是什么”和“人工希望在哪里设计”。将这些信息保留在 YAML 中，便于人工检查和病例间复用。

当前实验数据使用统一目录：

```text
../data/cases/single/tooth-<FDI>/
  case.yaml
  input/
    <来源牙列文件>.stl
    <来源导板文件>.stl
    <来源导管装配体>.stl
    <来源手机文件>.stl        # 可选
    handpiece-stop-NN.json    # 可选
  design/                     # 设计示意资料
  working/                    # 工程、中间文件和可选裁切参考
  output/                     # 参考或目标结果
```

STL 保留来源文件名，文件角色由 JSON 与 `case.yaml` 的显式路径表达。原“初始案例”
实际为缺失牙位 47 的黄金回归病例，因此病例目录为 `tooth-47`。程序生成结果写入
代码目录的 `output/`；病例自带的参考结果继续保存在病例 `output/` 中。

### 2.2 JSON：可执行工程配置

JSON 读取并融合 YAML 信息，同时保存程序运行需要的完整工程参数：

- 输入 STL 路径和输出目录；
- 导管尺寸、梁径、重叠量和网格分辨率；
- 切除体尺寸与边界余量；
- 各阶段开关及回退阈值；
- 验证阈值和生产复核状态。

因此，YAML 和 JSON 不是重复文件：YAML 负责病例语义，JSON 负责可执行参数。新增病例时只写 YAML 不一定足以生产；仍需有一个 JSON 将输入文件、工程尺寸和该 YAML 关联起来。

### 2.3 生产复核状态

配置中的“牙位、连接梁、Y 梁参数待确认”不是说参数缺失，而是说它们尚未经过人工审阅。参数可以完整到足以运行 `process` 或诊断，但正式 `generate` 会在显式 `pending` 状态下停止。完成渲染检查后再把对应状态改为已确认；仅在明确知道风险时使用 `--allow-unreviewed`。

## 3. 总体执行顺序

框架的阶段顺序为：

```text
读取并校验配置
  ↓
病例分析、导管识别与实体模式选择
  ↓
牙位识别、FDI 映射与坐标方向一致性检查
  ↓
规划导孔、操作窗和牙位观察窗
  ↓
规划可选的断裂导板跨接 / 末端 U 型延伸
  ↓
选择主连接梁的导管端和导板端锚点
  ↓
选择可选 Y 型按压梁锚点与汇合点
  ↓
生成主梁、按压梁和特殊梁中心线及扫掠网格
  ↓
牙列净距裁剪、末端强化和导板实体布尔融合
  ↓
按导管模式复切导孔并恢复观察窗，执行可选手机避让
  ↓
修复、导出、渲染和端到端验证
```

规划层入口位于 `src/twin_guide/generation_process.py`，实体建模入口位于 `src/twin_guide/guide_generation.py`。规划阶段使用 `GenerationContext` 传递中间结果，实体阶段再把这些几何计划转换为 Blender/Manifold 可处理的网格。

牙位识别、导板映射和观察窗算法已随 TwinGuide 源码分发，分别位于
`src/twin_guide/tooth_mapping/` 与 `src/twin_guide/observation_window_engine.py`。
运行时不调用上级工作区的历史脚本；外部依赖仅限 `pyproject.toml` 声明的
第三方数值、图像和网格库。

## 4. 步骤一：病例网格分析与导管重建

### 4.1 输入加载

程序加载三类主要网格：

- `template`：原始导板；
- `dentition`：牙列或牙列与牙龈；
- `sleeve assembly`：包含两根真实导管及可能的附属操作结构。

程序会采样导板和牙列表面，并把导管装配体分离为连通分量，为后续导管识别和操作特征测量做准备。

### 4.2 两根真实导管的识别

如果输入装配体包含多个分量，程序先检查每个候选是否具有真实轴孔：

- 沿拟合轴线的 15%、25%、35%、50%、65%、75%、85% 七个位置采样；
- 轴线采样点位于实体外部的比例必须不低于 0.60；
- 实心长杆或导孔占位 cutter 的轴线位于实体内部，因此在尺寸评分前排除；
- 可用候选少于两个时停止，不用尺寸接近的实心组件替代导管。

在通过轴孔检查的候选中枚举分量对，并按以下证据排序：

- 高度和外径是否接近期望导管尺寸；
- 两个候选轴线是否近似平行；
- 两分量的相对位置是否合理。

识别结果记录中心、轴线、轴向范围、C 口方向、源组件编号和轴向孔道通过率。
`generated` 模式主要消费识别位姿；`input` 模式同时保存所选输入网格，并在
真实导管外壁上确定 Q/P 接触关系。

### 4.3 轴线、上下端和 C 口方向

导管轴线由内孔和主体几何估计。当前语义约定为：

- `t_max`：C 形开口端，即几何高端；
- `t_min`：闭合孔端，即几何低端。

两根导管的 C 口朝向彼此，C 口反方向则作为主连接梁接触导管外壁的方向。两根轴线会先对齐符号，避免一根向上、一根向下导致后续高度和法向相反。

### 4.4 导管实体模式

病例 YAML 的 `design.sleeve_geometry.mode` 决定最终实体来源。

`generated` 模式按识别位姿和配置尺寸重建标准导管。这样做的好处是：

- 不受扫描网格噪声、破面或三角形密度影响；
- 导管内孔和外壁尺寸稳定；
- Q 点、P 点和最终复切孔道都能使用同一组解析参数；
- 不同病例得到一致的制造几何。

`input` 模式直接使用识别出的真实导管组件，保留其孔腔、开口和外形。程序不会
为了使输入实体通过检查而重新钻孔；若源导管本身没有通畅孔道，通道验证明确失败。
当前框架不自动保留其余装配体连通分量；操作特征只参与操作窗测量，不能作为附件
静默加入最终模型。

### 4.5 操作特征识别

两导管之间若存在圆柱形操作结构，程序从非导管分量中寻找靠近两导管中点且截面足够圆的候选。它的等效直径参与两导管间操作窗的短方向尺寸计算。

## 5. 步骤二：牙位识别、FDI 映射与方向校验

### 5.1 牙位工作流

牙位模块读取病例 YAML，生成新的牙位映射和报告。输出包含：

- 每颗牙的冠部点集和中心；
- FDI 编号与输入分割的对应关系；
- 牙弓局部切向 `local_tangent`；
- 指向牙弓外侧的 `local_outward`；
- 牙合方向 `e_occ`；
- 缺失牙位的预测槽位；
- 观察窗和锚点定位需要的牙位范围。

缺失牙或排除牙只用于牙弓序列推断，不会伪装成真实牙中心。

### 5.2 左右方向一致性检查

牙位识别本身正确，并不自动保证 FDI 左右方向与当前模型坐标一致。框架会对左右两个候选映射进行评分；当存在缺失种植牙位时，还会使用导管或手术位作为额外证据：

1. 预测缺失牙的位置是否接近导管/手术位；
2. 距离通常必须不大于约 15 mm；
3. 正确候选相对反向候选应至少改善约 3 mm；
4. 若证据不足则停止，而不是静默接受可能翻转的映射。

病例 YAML 提供显式坐标轴时，以人工轴为优先。该检查解决的是坐标方向问题，不会改变牙齿分割本身。

### 5.3 为什么后续几何依赖牙位映射

以下概念都不能只用全局 X/Y/Z 表达：

- U 型牙弓内侧与背 U 侧；
- 近中与远中；
- 指向导板外侧的牙合方向；
- 末端牙和相邻牙；
- 观察窗沿牙弓的起止位置。

因此所有基于牙位的锚点、U 型延伸和远中公共节点都使用牙位映射提供的局部坐标。

## 6. 步骤三：切除体规划

### 6.1 导孔

每根当前模式导管生成一个沿导管轴线的圆柱切除体。半径对应规划内孔，轴向范围
在导管上下端之外各保留一定余量。`generated` 模式用它复切最终整体；`input`
模式只用它清除导板和连接梁基础体对真实导孔的侵入。

### 6.2 两导管之间的操作窗

操作窗为圆角矩形切除体，其局部坐标为：

- 法向：两根已对齐导管轴线的平均方向；
- 长方向：两导管中心连线投影到法向平面后的方向；
- 短方向：法向与长方向的叉积。

尺寸规则为：

- 长尺寸 = 两导管中心距 + 两侧导管半径 + 长方向两侧余量；
- 短尺寸 = 操作特征直径 + `2 × planning.operation_windows.bitangent_margin_mm`；
- 深度 = 局部导板厚度和导管长度的较大值，再加两侧
  `planning.operation_windows.axial_margin_mm`；
- 圆角 = `planning.operation_windows.corner_radius_mm`。

这些病例级数值直接从 `case.yaml` 读取，并覆盖 JSON 中仅为旧病例保留的兼容默认值。
这里的“短方向”不等于屏幕截图中的横向；屏幕方向随视角变化，实际必须以上述局部坐标判断。余量过大可能切掉相邻导板或梁锚点，因此应按病例调整并通过渲染确认。

### 6.3 牙位观察窗

观察窗从 YAML 中的 FDI 区间生成，支持牙中心到牙中心或完整牙范围。其轴向由牙位映射的牙弓方向和牙合方向共同确定，不采用固定全局轴。

当前规划以较薄的轴向扫掠切片构造牙面窗口，并检查切除是否真实穿过导板。常规切片高度约 0.2 mm；单个轴向行未形成有效切口时可依次回退到 0.5、1.0、2.0 mm。若最终仍不满足观察窗 QA，则该病例失败关闭，不使用过去的固定 7 mm 粗略窗口替代。

观察窗面向唇颊侧外壁。输入导管模式在最终融合前用轮廓切除体复切，并按
“0.20 mm 验证净距＋半个融合体素”扩展 cutter，补偿最后一次体素融合造成的
边界回缩，避免窗口被重新封闭。

## 7. 步骤四：导管端 Q/P 锚点

### 7.1 Q 与 P 的定义

- `Q`：梁与导管外壁的真实表面接触点；
- `P`：梁中心线在导管端的锚点。

沿局部外壁法向，有：

```text
P = Q + (梁半径 - 预期融合量) × 法向
```

这样圆形梁表面与导管外壁有可控重叠，而中心线不会错误地落在导管表面。

### 7.2 高端与低端轴向位置

按当前定义：

```text
高端位置 = t_max - 2.0 mm - 梁半径
低端位置 = t_min + 1.0 mm + 梁半径
```

高端靠近 C 形开口端，低端靠近闭合孔端。`generated` 模式允许低端梁采用
依赖最终导孔复切的深埋；`input` 模式将低位梁限制为仅嵌入真实外壁 1.45 mm，
并在输入导管加入前从梁架基础体删除侵入导孔的部分。

两种模式的高端重叠都受导管壁厚和内孔净距限制。只有 `generated` 模式的低端
采用全直径深埋并依赖最终权威复切；`input` 模式不得把该假设用于真实导管。

## 8. 步骤五：基于牙位和射线的导板端锚点

### 8.1 为什么放弃轨迹百分比

早期方法在牙位切面与导板的整条交线上按 15/85、20/80 或 25/75 弧长取点。它存在三个问题：

- 导板边缘厚度也进入轨迹总长，百分比不再对应外侧支撑面；
- 内外壁或多个分量可能被串成一条轨迹；
- 锚点容易跑到导板顶部或同一侧。

当前保留 `tooth_section_trajectory` 这一兼容模式名，但实际不再使用轨迹弧长百分比。

### 8.2 牙位参考点 T

每个独立锚点的 `station` 可以是：

- `tooth_center`：单颗牙中心；
- `tooth_pair_midpoint`：两颗牙中心连线中点。

先取得该牙位附近冠部最高点 `H`，再沿指向导板外侧的正牙合方向向内偏置 2 mm：

```text
T = H - 2 mm × 正牙合方向
```

T 是射线旋转的原点，并不直接作为梁端点。

### 8.3 旋转面参考方向

只知道牙合方向还不能唯一确定旋转平面，还需要平面中的第二条轴：

- 双牙中点使用两牙中心连线；
- 单牙中心使用最近且被导板覆盖的邻牙中心连线。

该方向投影到牙合方向的法平面后，与牙合方向共同张成射线旋转面。`local_outward` 用于区分 U 型牙弓内侧和背 U 侧，避免误用固定世界坐标。

### 8.4 射线与导板外壁交点

从 T 沿正牙合方向开始，在旋转面内按照该锚点自己的 `side` 和
`ray_angle_degrees` 旋转，再与导板求交。主连接梁常用的起始参数是：

- U 侧射线 70°；
- 背 U 侧射线 90°。

Y 梁的每一个导板锚点都有自己的 `ray_angle_degrees`，不再自动统一选择角度。

求交时程序会：

1. 收集射线穿过网格的所有交点；
2. 合并距离小于约 0.02 mm 的重复交点；
3. 根据面法向和射线方向判断进入/离开；
4. 选择第一个有效外壁出口，而不是内壁入口。

主连接梁现在直接把外壁交点 `A` 作为中心线端点，不再创建考虑预埋量的 `S` 点。梁与导板可直接融合，侵入牙列的部分在牙列净距裁剪阶段切掉。

### 8.5 独立锚点与两导管的配对

两个端部各声明一个 U 侧和背 U 侧独立锚点。每个锚点可以使用不同牙位
轨迹和角度；正式病例迁移初值仍让同端部两锚点使用相同牙位，以保持既有
几何。程序在可行配对中最小化总连接距离，使每根导管分别得到：

- 一个来自站位 1 的导板锚点；
- 一个来自站位 2 的导板锚点。

这样高、低两条梁均跨接两个导板区域，形成连续框架，而不是把同一牙位的两个点都分给同一根导管、造成左右两个独立框架。

## 9. 步骤六：四根主连接梁

### 9.1 总体拓扑

每根导管生成两根梁：

```text
        P高
       /   \
     A−     A+
       \   /
        P低
```

两根导管共四根连续梁。默认梁直径为 4.60 mm。

### 9.2 高端梁曲线

高端梁由两段五次 Hermite 曲线组成：

```text
A− → P高 → A+
```

两段在 P 点共享一阶导数，端点二阶导数为零，从而获得连续、平顺的连接，避免简单折线在导管附近形成尖角。

### 9.3 低端梁的下潜策略

低端梁先构造一条外层代理曲线，再在 P 低点附近约 5 mm 弧长范围内局部下潜。当前策略为：

- 左拼接点沿原曲线左侧切向进入下潜段；
- 右拼接点沿原曲线右侧切向离开下潜段；
- 只有深埋 P 点使用左右拼接点连线投影得到的方向。

这替代了曾经用同一个方向控制整个下潜段的做法。旧做法会让左右拼接点的切向与外层曲线不连续，表现为异常弯折；当前方法保留了原曲线在两侧的自然走向。

### 9.4 离散和圆管扫掠

中心线通常按约 0.30 mm 间距重采样。圆形截面沿曲线采用平行传输框架扫掠，避免 Frenet 框架在低曲率或拐点处突然翻转。圆周分辨率通常为 64。

### 9.5 末端强化

连接梁与导板连接处采用两层强化：

- 最后约 3 mm 内将梁半径逐步放大到约 1.08 倍；
- 每个唯一导板端点增加球头和贴合脚 `bulb_and_conformal_foot`。

贴合脚根据局部导板表面缩放并预埋约 0.25 mm，使接触不只是一条圆管端面。强化几何同样要经过牙列净距裁剪。

## 10. 步骤七：Y 型按压梁

Y 型梁有三种当前支持的锚点模式。三种模式共享梁直径、圆管扫掠、汇合球和导板端强化，但锚点与汇合点规则不同。

### 10.1 `inner_sleeve_upper_y`

适用于一个锚点位于导管、另两个锚点位于导板的情况。

1. 对每根导管寻找最近牙位；
2. 按该牙位的 `local_outward` 坐标选择 U 型牙弓内侧导管；
3. 导管端复用该导管的高端 `Q/P`；
4. 两个导板端分别使用 YAML/JSON 中显式设置的牙位类型和射线角度。

汇合点先由三个锚点的几何中位数估计，并比较它与导管高端 P 在导管正轴向上的高度：

- 若导管 P 不低于原中心，保留原规则，将中心投影到导管 P 的轴向等高平面；
- 若导管 P 低于原中心，不再向下对齐，而是从原中心沿导管正轴向抬高 `junction_axial_lift_mm`，默认 2 mm；
- 在两种高度分支中，若汇合点到导管 P 的距离小于 6 mm，则仅调整轴向垂直平面内的径向分量，使距离达到 6 mm；距离已经大于或等于 6 mm 时保留原位置。

因此 6 mm 是最小距离，不是强制固定距离。

### 10.2 `three_tooth_anchors_y`

适用于三个锚点全部位于导板的情况。每个锚点都可独立使用 `tooth_center` 或 `tooth_pair_midpoint`，并拥有自己的射线角度。

汇合点先取三个锚点中心，再沿牙合/压合方向 `e_occ` 抬高，默认 2 mm。这里不使用导管轴线，也不应用 6 mm 规则。抬高的目的只是使按压位置便于操作，并避免汇合点落到三个导板锚点平面以下。

### 10.3 `terminal_u_extension_anchor_y`

适用于一个 Y 梁锚点落在末端 U 型延伸梁上的情况。另两个锚点仍由牙位射线确定。

U 梁锚点在允许的 U 型中心线范围内，选择使其到另外两个导板锚点的**最小距离最大**的点：

```text
arg max min(distance(point, anchor_1), distance(point, anchor_2))
```

它比“距离某个参考牙最近”更能把第三个锚点拉开，形成稳定三角形。当前可配置是否排除中心线首尾范围；#14 允许使用远端转角，因此不排除最后 4.60 mm。`overlap_mm = 1.00` 用于让该 Y 臂与 U 梁有更可靠的实体重叠。

### 10.4 Y 梁几何质量约束

三条 Y 臂在一个公共汇合点相交，汇合处加入约 1.12 倍梁半径的球形过渡。程序还按 `minimum_junction_angle_degrees` 检查过小夹角（默认 25°），避免三条梁近乎重合而失去按压和支撑意义。

## 11. 步骤八：特殊病例拓扑

### 11.1 #13：两块断裂导板的同侧双梁跨接

当导板恰好有两个主要连通分量时，可启用 `guide_component_bridge`：

1. 配置两个牙位站位；
2. 每个站位分别发射 U 侧和背 U 侧射线；
3. 要求同一站位的候选锚点落在不同导板分量；
4. 比较“分量 1→2”和“分量 2→1”两种分配，选择总射线距离较小者；
5. U 侧锚点互连、背 U 侧锚点互连，生成两根 4.60 mm 跨接梁；
6. 两端使用球头与贴合脚强化。

该接口针对“两个主要导板分量”这一可复用拓扑，但不会猜测三个以上碎片应如何连接；分量数与配置不符时应失败并要求人工检查。

### 11.2 #14：末端 U 型延伸梁

当原导板末端覆盖过短、需要绕末端牙延伸支撑时，可启用 `guide_terminal_u_extension`。

约束为：

- 末端牙和参考邻牙必须在同一象限且直接相邻；
- 末端牙必须是该象限实际存在的最远端牙；
- 两个根部锚点由已有 U/背 U 射线规则确定。

远中方向由“参考邻牙中心 → 末端牙中心”在牙合平面上的投影得到。U 型回转端优先使用独立闭合牙冠轮廓估计远中和左右包络；无法得到可靠轮廓时才回退到局部牙列网格包络。

梁中心线到牙面的计划余量为：

```text
梁半径 + dental_clearance_mm + safety_margin_mm
```

常用牙面净距 0.20 mm、额外安全余量 0.30 mm，即梁表面计划离牙约 0.50 mm。回转深度控制曲线形状，不应重复增加牙面净距，否则会出现远端余量过大。两侧采用五次曲线并以自然切向进入、离开 U 型回转。

牙列与牙龈可能是同一张网格，因此验证时不能用整条 U 梁到整张牙龈网格的全局最小距离代替牙冠净距；应验证规划牙冠轮廓、延伸方向和中心线保留率。

### 11.3 #17：末端牙缺失的远中公共梁中心节点

当末端种植位远中没有导板覆盖时，可启用 `terminal_distal_common_node`。目标是让末端两根导管的四根主梁在一个远中自由节点闭合，而不是强行寻找不存在的导板锚点或牙龈接触点。

当前定位过程为：

1. 取末端两根导管低端 P 点连线的中点作为出发基点 `B`；
2. 用两导管中心连线与公共导管轴线的叉积得到横向候选；
3. 根据“参考邻牙 → 缺失末端牙槽位”的牙位方向选定远中符号；
4. 计算末端两根导管的平均外径 `D`；
5. 直接令 `G = B + 2D · e_distal`；
6. 四根主连接梁都使用同一个 `DISTAL_COMMON_NODE` 端点。

这里不再向牙龈/牙列网格发射射线，也不执行根方下压、表面法向偏移、组织净距或最大投射距离计算。因此 `G` 与 `B` 保持相同的导管轴向高度，其位置只由 `B`、远中方向和两个平均导管外径决定。

端点来源使用明确枚举 `DISTAL_COMMON_NODE`，多边形索引为空，不再用 `polygon_index = -1` 表示特殊状态。这样后续强化、验证和序列化可以按端点语义分支，不会把自由节点误当成导板三角面或牙龈表面点。

对于 16、17 两个相邻末端种植位，使用
`adjacent_two_implant_terminal_distal_node_paths`。近中站位产生 U 侧与背 U
侧两个导板锚点，每侧路径依次经过 16 和 17 对应导管，最后到达同一
远中公共节点：

```text
S_mesial,U    → P16,U    → P17,U    → G
S_mesial,back → P16,back → P17,back → G
```

上下端分别构造一次，因此仍是四根主梁。节点投射基点必须取远中种植位
17 的两根导管下端 P 中点，不能取前两根导管或四根导管的总体中心。
由于牙列 STL 同时包含牙龈，常规牙体净距差集可能误切掉末端梁到自由
节点的闭合段。因此实体化阶段仅保护远中导管 P 到公共节点 G 的闭合
段；近中导板段和种植位之间的其余连接梁仍执行牙列净距裁剪。

### 11.4 特殊模式互斥

`guide_terminal_u_extension` 和 `terminal_distal_common_node` 当前不能同时启用。原因不是两种几何在理论上绝对冲突，而是它们代表病例级的两种不同末端策略：

- 末端牙存在：绕牙生成 U 型支撑；
- 末端牙缺失：把四根梁闭合到远中自由公共节点。

当前配置和验证器都假定只有一个末端目标。若未来确有同一病例两侧分别使用不同策略的需要，应把接口扩展为按象限/侧别配置，而不是取消互斥后让两个全局模式同时修改相同端点。

## 12. 步骤九：牙列净距裁剪与实体融合

### 12.1 牙列保护

主梁、Y 梁和强化脚生成后，会用按 `dental_clearance_mm` 膨胀的牙列保护体裁剪。这样导板端锚点可以直接位于导板外表面 A，梁与导板充分融合，同时侵入牙齿的部分被删除。

净距裁剪最容易受输入牙列非流形、巨大三角面或错误牙位分量影响，因此出现梁突然缺段时应先检查裁剪前中心线和牙列保护体，而不是只检查最终 STL。

### 12.2 `generated` 模式布尔顺序

生成导管模式按以下顺序构造：

1. 从原导板切除初始导孔、操作窗和观察窗；
2. 体素融合已切导板、标准导管、主梁、Y 梁和特殊梁；
3. 对融合体进行体素规整；
4. 使用精确布尔再次切除导管内孔；
5. 再次切除牙位观察窗轮廓；
6. 可选执行手机避让差集；
7. 修复并导出 STL。

该模式先融合、后复切导孔。若只在融合前切孔，重建导管壁、预埋低端梁或
体素化都可能重新堵塞内孔。导孔和观察窗复切后执行“保留最大连通体”，并在
需要时执行受控 STL 序列化修复。

### 12.3 `input` 模式布尔顺序

输入导管模式按以下顺序构造：

1. 从原导板切除初始导孔、操作窗和观察窗；
2. 体素融合已切导板、主梁、Y 梁和特殊梁，得到不含输入导管的基础体；
3. 从基础体复切导孔和观察窗，删除连接梁侵入导孔的部分；
4. 对基础体执行可选手机避让差集；
5. 将识别出的输入导管作为受保护实体最后融合；
6. 只删除体积小于 1.5 个融合体素的数值碎片，清理并导出 STL。

输入导管加入后不再全局复切导孔，也不执行“只留最大连通体”。因此真实导管
不会被连接梁 cutter 或旧版连通体规则删除；具有实际体积的独立组件不会被
微小体素碎片清理误删。1.5 个体素的阈值覆盖 Blender 偶发生成的单体素闭合
立方体，但远小于真实导管或附件体积。

## 13. 步骤十：手机避让

手机避让由 `handpiece_avoidance` 显式启用，可对一个或多个导板分区执行。

方法为：

1. 读取当前手机姿态 STL 和止挡报告；
2. 以配置的 `pair_axis` 为旋转轴，以止挡面中点为枢轴；
3. 在左右约 ±5° 范围内采样，常用 41 个奇数采样以确保包含 0°；
4. 不额外考虑轴向下压深度；
5. 先将所有姿态精确合并为扫掠包络；
6. 从最终导板整体依次做差集。

该切除不保护梁架：进入手机包络的导板或梁都会被切掉，因此必须检查避让后
连接梁是否仍连续。`input` 模式在该差集之后才融合受保护输入导管，所以手机
包络不会修改真实导管；`generated` 模式的重建导管属于整体差集对象。

手机扫掠较耗时，主要成本来自多个高分辨率 STL 姿态的精确并集和最终差集。程序可按输入与参数哈希复用包络缓存。正常生产不应额外生成一份“无避让对照模型”；这种额外对照或完整比较必须先取得用户许可。

## 14. 步骤十一：导出、渲染与质量验证

### 14.1 常规输出

每次生成通常输出：

- 最终 STL；
- 规划/过程 JSON 报告；
- 牙位映射和牙位 QA 报告；
- 导管、锚点、中心线、切除体等调试网格；
- 等轴、顶视、底视、侧视等渲染图；
- 验证报告和失败原因。

具体路径由病例 JSON 的输出配置决定，不应假定所有病例都写入同一个固定目录。

### 14.2 拓扑检查

最终 STL 至少检查：

- 网格闭合且流形；
- 无退化面和重复面；
- 无非期望的多个连通分量；
- 修复后体积和包围盒没有异常跳变。

顶点焊接、删除退化面和重复面通常只消除数值冗余，不应明显改变正常对象的外形；若属性或体积明显变化，说明原网格存在大范围自交、重叠壳或错误容差，不能把修复结果直接视为可靠。

### 14.3 结构检查

验证器会独立重建期望规划，并检查：

- 当前模式导管在最终模型中的保留率；输入模式还记录源组件编号和轴向孔道通过率；
- 主梁中心线的包覆率和连续性；
- 梁端是否接近预期导管/导板/牙龈锚点；
- 每个唯一导板端的强化结构是否存在；
- Y 梁三臂、汇合点和贴合脚是否保留；
- #13 跨接梁是否连接不同导板分量；
- #14 U 梁根部、远端转角、远中方向和计划牙面净距是否合理；
- #17 是否恰有四条梁共享同一牙龈端点，以及投射基点、远中偏移、根向射线和节点保留是否正确。

### 14.4 切口检查

- 导孔用多组探针点检查是否贯通，避免仅检查中心一点；
- 导孔报告记录是否保护输入几何、是否对生成导管执行全局复切，以及是否只在
  输入导管加入前复切连接梁基础体；
- 观察窗检查轮廓是否保留足够净距；
- 操作窗检查尺寸和方向是否符合局部导管坐标；
- 手机避让目前主要在生成阶段验证布尔结果，完整验证器尚不独立重建整个手机扫掠包络。

推荐正式生成使用 `generate --validate`。若验证失败，应保存中间产物定位问题，不应只靠最终渲染猜测。

## 15. 性能与耗时来源

不同阶段的典型成本如下：

| 阶段 | 相对成本 | 主要原因 |
| --- | --- | --- |
| 配置解析、锚点数学、曲线计算 | 低 | 点和向量运算 |
| 导管识别、牙位射线求交 | 低到中 | 网格采样与空间查询 |
| 牙位识别工作流 | 中到高 | 分割、排序、映射和报告 |
| 观察窗布尔 | 高 | 多个轮廓切除体与复杂导板求差 |
| 梁对牙列净距裁剪 | 高 | 复杂网格膨胀/差集 |
| 全部结构体素融合 | 高 | 高分辨率三维体素化和重建 |
| 手机扫掠包络与差集 | 很高 | 多姿态精确并集及最终布尔 |
| 完整端到端验证 | 中到高 | 重新规划、载入并逐项几何检查 |

为减少无效耗时，推荐按“规划 → 局部渲染 → 完整生成 → 完整验证”逐级执行。修改一个射线角度后，可先生成目标病例结果并做必要的局部检查；除非用户明确许可，不额外生产对照 STL、重复完整单元测试或无关病例批处理。

## 16. 新病例的推荐落地流程

### 16.1 输入与解剖语义

1. 准备导板、牙列/牙龈、导管装配体；
2. 在 YAML 中填写上下颌、实存/缺失牙和观察窗；
3. 确认 FDI 左右映射与缺失种植位一致；
4. 判断导板是普通单分量、两分量断裂、末端覆盖短，还是末端缺牙无覆盖。

### 16.2 选择结构模式

- 普通病例：四根主连接梁，按需增加 Y 梁；
- 两块断裂导板：增加 `guide_component_bridge`；
- 末端牙存在但导板过短：增加 `guide_terminal_u_extension`；
- 末端牙缺失且远中无导板：增加 `terminal_distal_common_node`；
- 需要按压：在三种 Y 梁模式中选择与病例拓扑一致的一种；
- 需要手机操作空间：增加 `handpiece_avoidance`。

### 16.3 参数与预览

1. 为每个导板锚点明确填写 `tooth_center` 或 `tooth_pair_midpoint`；
2. 为每个 Y 梁导板锚点明确填写射线角度；
3. 先运行流程规划，查看牙位、T 点、射线、外壁交点、Q/P 和中心线；
4. 再检查操作窗宽度、观察窗位置和特殊结构方向；
5. 对失败的射线或映射修正病例语义，不用扩大容差掩盖错误。

### 16.4 正式生产

1. 运行完整生成并导出渲染；
2. 人工确认牙位、梁锚点、Y 梁、窗口和避让；
3. 更新生产复核状态；
4. 运行 `generate --validate`；
5. 保存最终 STL、配置、映射、验证报告和必要调试图，形成可追溯病例包。

## 17. 常见问题定位顺序

### 锚点跑到导板顶部

依次检查：牙合方向符号、旋转面的邻牙参考方向、射线角度、交点进出判定、是否选中了错误导板分量。不要再回退到整条切面轨迹百分比。

### 两个锚点落在同一侧

检查 `local_outward`、U/背 U 射线符号和导板分量标签；屏幕左右不能替代牙弓 U/背 U 语义。

### 低端梁异常弯折

检查下潜段两侧拼接点是否继承外层曲线各自切向；只有深埋 P 点才能使用合并点连线方向。

### 导孔堵塞或观察窗消失

检查最终融合后是否执行权威复切，以及复切体是否覆盖完整轴向范围。体素融合前的切口存在并不能证明最终孔道存在。

### 导板末端被大量切掉

检查 `operation_bitangent_margin_mm` 和手机扫掠包络；操作窗短方向余量过大或手机姿态扫掠都可能删除附近梁锚点。

### 特殊梁方向反了

检查牙位映射左右一致性、邻牙到末端牙的远中向量，以及 #17 叉积候选的符号选择。不要通过手工翻转全局 X/Y 临时修复单病例。
