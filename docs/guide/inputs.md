# 输入数据

## 网格文件

| 配置字段 | 内容 | 用途 |
| --- | --- | --- |
| `objects.guide.path` | 带定位圆环的传统模板 STL | 估计导柱位置，并作为开孔、开窗和连接的基体 |
| `objects.dental.path` | 患者牙列扫描 STL | 识别牙位并计算导板映射与结构净距 |

每个种植位必须在 `planning.guide_posts` 中指定一个传统模板圆环及对应的
钻针长度、植体长度和套环导板延长量。程序不读取导管装配体 STL。

以上网格必须使用同一世界坐标系，长度单位为毫米。
文件中的转换矩阵应在导出 STL 前应用，避免几何位置与表面顶点不一致。

病例目录为 `../data/cases/<cohort>/<case>/`。病例 YAML 位于病例根目录，
输入文件放在 `input/`：

```text
../data/cases/<cohort>/<case>/
  case.yaml
  input/
    <来源牙列文件>.stl
    <来源导板文件>.stl
    <来源手机文件>.stl
    handpiece-stop-01.json
```

STL 保留来源文件名；`case.yaml` 通过显式相对路径声明文件角色，
不要求为了程序运行复制或重命名输入网格。

生成结果统一写入项目的 `output/`，不写回病例数据目录。完整文件角色和
病例数据目录说明见 `../data/README.md`。

`jaw` 是必填病例语义，与 FDI 分类及可选的 `anatomy.orientation` 共同确定牙弓方向、
牙位顺序和观察窗的牙合/颊唇侧。
导柱轴向由传统模板圆环上平面确定；两个 C 口分别沿两导柱中心连线指向对侧导柱。

## 网格要求

- STL 文件只包含一个可导入网格对象。
- 牙科导板和患者牙列应保留实际表面尺寸和位置。
- 每个定位圆环必须具有可稳定拟合的圆形内边界和上平面。
- 严重的自相交、重复面和退化三角形应在导入前修复。

启用 `handpiece_avoidance` 时还需提供与病例处于同一世界坐标系的手机 STL，
以及已经匹配双侧止挡面的 JSON 报告。当前只采用手机最大面积连通分量，且不做
轴向下压。
