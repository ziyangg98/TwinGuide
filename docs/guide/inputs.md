# 输入数据

## 网格文件

| 配置字段 | 内容 | 用途 |
| --- | --- | --- |
| `inputs.template` | 牙科导板 STL | 作为开设导孔与窗口、连接导套的基体 |
| `inputs.guide_sleeve_assembly` | 导套装配体 STL | 识别导套、操作结构和装配关系 |
| `inputs.patient_dentition` | 患者牙列扫描 STL | 当前代码用于装配参照和渲染；预留给牙位识别和牙列净距检查 |

三个网格必须使用同一世界坐标系，长度单位为毫米。
文件中的转换矩阵应在导出 STL 前应用，避免几何位置与表面顶点不一致。

## 网格要求

- STL 文件只包含一个可导入网格对象。
- 牙科导板和患者牙列应保留实际表面尺寸和位置。
- 导套装配体的各结构应为可分离的连通分量。
- 严重的自相交、重复面和退化三角形应在导入前修复。

## 检查输入

`validation.handpiece.mesh` 指向牙科手机 STL。该网格与导套初始姿态使用同一坐标系，
用于计算机头和撤离路径与牙科导板的净距。
该网格只在执行 `validate` 时必需，生成 STL 时可以不配置 `validation`。
