# 模块边界

| 模块 | 当前输入 | 当前输出 |
| --- | --- | --- |
| 导套识别与参数化重建 | 导套装配体、牙科导板定向几何 | 两个重建导套和局部标架 |
| 导孔与窗口规划 | `CaseAnalysis`、`SleeveGenerationResult` | `WindowCutoutPlan` |
| 联建锚点选择 | 导套、牙科导板、导孔与窗口 | 导套与牙科导板锚点 |
| 光滑连接管生成 | 联建锚点 | 八条曲线的控制点、中心线和实体化参数 |

牙位识别、按压梁柱锚点选择和避让空间调整仅保留目标接口，不在当前模块数据流中。
前牙观察缺口使用患者牙列表面定位，不依赖单颗牙齿标签。

## 几何层

几何层计算点、向量、曲线、距离和参数化结果。
步骤之间通过结果类型传递数据，不调用其他步骤的私有函数。

## Blender 层

Blender 层将几何计划转换为网格。切割体、曲线管、布尔融合、固定孔复切、
体素重网格化和 STL 导出均在该层完成。

## 检查层

检查层读取导出 STL 和病例配置，独立计算拓扑、尺寸、连通性和净距指标。
检查函数不修改导出网格。
