# 模块边界

| 模块 | 当前输入 | 当前输出 |
| --- | --- | --- |
| 导管识别与实体模式选择 | 导管装配体、牙科导板定向几何、YAML 模式 | 两个当前模式导管、源组件审计信息和局部标架 |
| 导孔与窗口规划 | `CaseAnalysis`、`SleeveGenerationResult` | `WindowCutoutPlan` |
| 联建锚点选择 | 导管、牙科导板、导孔与窗口 | 导管与牙科导板锚点 |
| 连续梁架生成 | 联建锚点 | 四根连续中心线、接触点索引和扫掠参数 |

牙位识别、按压梁锚点选择和避让空间调整均已接入当前模块数据流；未配置的
可选阶段以 `skipped` 记录。观察窗使用 FDI 牙位映射、牙弓局部方向和病例 YAML
端点定位，不再采用无单牙语义的固定前牙缺口。

## 几何层

几何层计算点、向量、曲线、距离和参数化结果。
步骤之间通过结果类型传递数据，不调用其他步骤的私有函数。

## Blender 层

Blender 层将几何计划转换为网格。切割体、平行输运圆截面扫掠、布尔融合、
按导管模式安排的固定孔复切、体素重网格化和 STL 导出均在该层完成。

## 检查层

检查层读取导出 STL 和病例配置，独立计算拓扑、尺寸、连通性和净距指标。
检查函数不修改导出网格。
