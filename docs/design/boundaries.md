# 模块边界

| 模块 | 输入 | 输出 |
| --- | --- | --- |
| 导柱定位与标准重建 | 传统模板圆环、规划参数、标准尺寸 | 两个标准重建导柱和局部标架 |
| 导孔与窗口规划 | `CaseAnalysis`、`SleeveGenerationResult` | `CutoutPlan` |
| 导管—导板锚点选择 | 导管、牙科导板、导孔与窗口 | 导管与牙科导板锚点 |
| 连续梁架生成 | 导管与导板锚点 | 四根连续中心线、接触点索引和扫掠参数 |

牙位识别、按压梁锚点选择和避让空间调整通过类型化结果接入模块数据流。
观察窗由 FDI 牙位映射、牙弓局部方向和病例 YAML 端点确定。

## 几何层

几何层计算点、向量、曲线、距离和参数化结果。
步骤之间通过结果类型传递数据，不调用其他步骤的私有函数。

## Blender 层

Blender 层将几何计划转换为网格。切割体、平行输运圆截面扫掠、布尔融合、
整体融合后的固定孔复切、体素重网格化和 STL 导出均在该层完成。

## 检查层

检查层读取导出 STL 和病例配置，独立计算拓扑、尺寸、连通性和净距指标。
检查函数不修改导出网格。
