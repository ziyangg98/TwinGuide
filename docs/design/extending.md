# 扩展与测试

## 实现生成步骤

1. 定义输入配置和不可变结果类型。
2. 在步骤函数的 docstring 中写明参数、返回值、异常和执行顺序。
3. 使函数只读取声明的上游结果。
4. 将结果字段加入 `GenerationContext`，由生成控制写入。
5. 从 `twin_guide` 导出公开函数和结果类型。
6. 几何结果需要转换为网格时，在 Blender 层增加实体化函数。

## 测试层次

| 目录 | 职责 |
| --- | --- |
| `tests/unit/` | 数据类校验、纯几何函数、边界条件和文档完整性 |
| `tests/blender/` | STL 读写、网格查询、布尔运算和实体化 |
| `tests/end_to_end/` | 病例配置、已实现步骤的数据传递、STL 导出和结果检查 |

## 接受条件

- 公开类和函数具有中文 docstring。
- 几何函数在无 `bpy` 环境中可导入。
- Sphinx 严格构建无警告。
- 单元测试、Blender 集成测试和当前病例端到端测试通过。
